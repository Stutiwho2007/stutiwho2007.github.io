# MINHO Website

A responsive static website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — homepage structure and content
- `style.css` — editorial cream styling, responsive layout, and subtle transitions
- `script.js` — mobile menu, scroll reveals, reading modals, enquiry form
- `assets/` — add your logo, founder photo, and any other image assets here

## Preview on your laptop
1. Download and extract `MINHO-Website.zip`.
2. Open the `MINHO-Website` folder.
3. Double-click `index.html` to preview in your browser.
4. Optional: open the folder in Visual Studio Code and use the Live Server extension.

## Before launch
1. In `script.js`, replace `hello@minhostudio.com` with your real enquiry email.
2. Confirm the package prices, inclusions, revision rounds, and offer terms.
3. Replace the sample portfolio excerpts if you want to show only final work.
4. Add your logo or founder photo in `assets/` if desired. This version uses a CSS-built wordmark and CSS artwork, so no images are required.
5. The enquiry form opens a drafted email; it does not save enquiries to a database or send them automatically.
6. The homepage does not take payments. Add tested payment links only when you're ready.

## Publish to GitHub Pages
1. Make a backup of your current repository first.
2. Open the repository `stutiwho2007.github.io`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root (not a nested folder).
4. Commit the changes to the branch GitHub Pages uses (usually `main`).
5. Wait for the Pages deployment, then visit `https://stutiwho2007.github.io/`.
6. Test the mobile menu, portfolio excerpts, form, links, and all three package cards.

This is a front-end-only site: no backend, database, or payment processing is included.
